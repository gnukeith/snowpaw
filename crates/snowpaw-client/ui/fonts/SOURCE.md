Figtree, by The Figtree Project Authors, licensed under the SIL Open Font License 1.1
(see `OFL.txt` in this folder). It is compiled into the client as the default UI font;
users can switch to the system font or any installed font in Settings.

Source: https://github.com/erikdkennedy/figtree, commit
`032dfa7fe219ef3a02890d6d3add84eacc9aebfe`, files `fonts/ttf/Figtree-{Regular,Medium,SemiBold,Bold}.ttf`
